# Proyecto Integrador - Laboratorio de Red Personal

## Descripción

Este proyecto integra los conocimientos adquiridos durante las prácticas anteriores mediante el diseño, implementación y documentación de un pequeño laboratorio de red.

El laboratorio incluye servicios de red, análisis de tráfico y comunicación entre sistemas Windows y Linux, simulando una infraestructura básica similar a la de un entorno empresarial.

## Objetivos

- Integrar los conceptos aprendidos durante el proyecto.
- Configurar un servidor con servicios de red.
- Analizar el funcionamiento de los principales protocolos de comunicación.
- Documentar la infraestructura y las decisiones de diseño.
- Crear un laboratorio funcional para prácticas de administración de redes.

## Infraestructura

El laboratorio está compuesto por:

- Windows Server
  - Servidor DHCP
  - Servidor DNS

- Ubuntu Desktop
  - Cliente Linux

## Tecnologías y protocolos utilizados

- DHCP
- DNS
- TCP/IP
- ICMP
- SSH
- Wireshark
- Windows Server
- Ubuntu Desktop
- VirtualBox

## Contenido del proyecto

- Informe técnico final.
- Diagrama de la red.
- Configuración del servidor DHCP.
- Configuración del servidor DNS.
- Configuración del cliente Ubuntu.
- Capturas de tráfico realizadas con Wireshark.
